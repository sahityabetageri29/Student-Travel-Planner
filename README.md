**WanderStudent** is a sophisticated web application designed to help students explore India on a budget. It leverages AI to generate personalized trip itineraries, budget breakdowns, and packing lists based on real-time student constraints.


---

## ✨ Key Features

- **AI Trip Generation**: Integrated with Claude Sonnet to provide detailed JSON-based itineraries including day-wise plans and travel routes.
- **Dynamic Theming**: Features a custom-coded background system that shifts between "Day" and "Night" modes with animated mountains, stars, and clouds.
- **Smart Budgeting**: Includes an expense tracker and visual breakdown using `recharts` (Pie and Bar charts) to monitor spending vs. budget.
- **Curated Destinations**: Pre-loaded data for popular Indian student hubs like Rajasthan, Kerala, Himachal, and Goa.
- **Immersive UI**: High-end glassmorphism design with custom keyframe animations for a premium user experience.

## 🛠️ Tech Stack

- **Framework**: React.js
- **Styling**: Pure CSS-in-JS with high-performance keyframe animations.
- **Visualization**: `recharts` for financial data analysis.
- **AI Integration**: Anthropic Claude API for travel intelligence.
- **State Management**: React Hooks (`useState`, `useEffect`, `useRef`).
